Show the uncle-bob-junior reference card. One shot, change nothing. Levels: lite (readability pass only: names, guard clauses, named constants on touched code), full (the whole checklist enforced, tests included, default), ultra (hard limits: functions max ten statements, nesting max 2, every branch tested, adjacent smells cleaned). Skills: /uncle-bob-junior (clean-code mode), /uncle-bob-junior-review (diff smell review), /uncle-bob-junior-audit (repo-wide smell audit), /uncle-bob-junior-debt (ubj: deviation ledger), /uncle-bob-junior-gain (with/without benchmark scoreboard), /uncle-bob-junior-help (this card). Deactivate: 'stop uncle-bob-junior' or 'normal mode', or /uncle-bob-junior off. Default mode via UNCLE_BOB_JUNIOR_DEFAULT_MODE env var or ~/.config/uncle-bob-junior/config.json (defaultMode: lite); resolution env var > config file > full.
